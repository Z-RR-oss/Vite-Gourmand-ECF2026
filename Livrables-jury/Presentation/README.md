# Présentation orale

- [PowerPoint modifiable](Vite-Gourmand-Oral.pptx) : 16 diapositives principales et 3 annexes MCD, format 16:9. Le script figure dans les notes du présentateur.
- [Script imprimable en PDF](Script-oral-Vite-Gourmand.pdf).
- [Script modifiable en Markdown](Script-oral-Vite-Gourmand.md).

Le minutage proposé est de 15 minutes 50 secondes, dont 2 minutes de démonstration. Adapter ce format à la durée officielle de l'examen. Répéter à voix haute et personnaliser les formulations.

Le support présente l'état réel du projet : CSS responsive issu d'une base desktop, mockups documentés après le développement, contrôles ciblés sans certification RGAA exhaustive. Les chiffres de tests correspondent à la recette du 1er octobre 2026. Les captures statistiques utilisent des données fictives de septembre 2026.

Vérification : 19 diapositives et 19 notes présentes, trois tableaux PowerPoint modifiables, contrôles de structure et de géométrie sans anomalie, réimportation réussie et inspection des rendus. Le diaporama n'a pas été exécuté dans Microsoft PowerPoint ; ouvrir le fichier sur l'ordinateur utilisé pour l'oral et vérifier le mode Présentateur avant l'examen.
